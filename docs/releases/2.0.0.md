# Palomar 2.0.0

Palomar 2.0.0 establishes the clean-break Palomar product identity across the
Linux service and CLI, web/PWA client, Android application, package metadata,
release artifacts, documentation, and repository presentation.

- Palomar runs Codex and Claude Code on persistent, always-on Linux hosts.
- Android and web remain direct remote control surfaces over trusted LAN,
  Tailscale, or WireGuard connectivity; no hosted relay is required.
- The Linux command and service are `palomar` and `palomar.service`.
- Android uses the `net.kaltner.palomar` application ID and package namespace.
- Release artifacts and signed manifests use Palomar-specific names.

This release intentionally does not migrate pre-2.0 installations or client
storage. Install it as a new Palomar deployment.
