# Foreman v1.2.1

Foreman v1.2.1 completes the project's move to the Apache License 2.0 and
refreshes the public documentation around its persistent-host architecture.

## Highlights

- **Apache-2.0 licensing.** Foreman's original source code and first-party
  release contents are distributed under the Apache License 2.0. Third-party
  components remain under their respective licenses and terms.
- **Self-contained license information.** The Linux archive continues to ship
  `LICENSE` and `THIRD_PARTY_NOTICES.md`; the Android APK now embeds both files
  as assets as well.
- **Clearer product positioning.** The README now presents Foreman as a
  self-hosted control plane for persistent Linux coding hosts, with native
  Android and responsive web clients as remote control surfaces.
- **More practical onboarding.** Installation and first-run guidance now makes
  provider requirements, verified release installation, pairing, private
  networking, and headless-host service persistence easier to follow.

## Release assets

- `foreman-linux-v1.2.1.tar.gz`
- `foreman-v1.2.1.apk`
- `SHA256SUMS`
- `SHA256SUMS.sig`
- `foreman-release-cert.pem`

The Linux archive and Android APK are accepted only when their checksums and
the signed release manifest validate against Foreman's pinned release
certificate.
