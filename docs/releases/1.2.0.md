# Foreman v1.2.0

Foreman v1.2.0 improves multi-client administration, usage visibility,
appearance consistency, and session organization across web and Android.

## Highlights

- **Connected-device management.** Web and Android show paired and currently
  connected clients, with host-scoped controls to revoke another client's
  access.
- **Complete account-usage visibility.** Usage details retain and display every
  reported provider limit while compact meters summarize the tightest active
  window and the number of additional limits.
- **Stable session organization.** Repository groups remain in natural
  alphabetical order as activity changes, while active sessions continue to
  rise within their own group.
- **Coherent themes and branding.** Semantic badges, status treatments, Foreman
  logos, About surfaces, and the Android notification icon now adapt cleanly to
  the selected theme.

## Fixes and polish

- Restored completed image-view and web-search history items that do not carry
  a provider status field.
- Simplified the README and documented systemd user lingering for hosts that
  should keep Foreman running without an interactive login.

## Release assets

- `foreman-linux-v1.2.0.tar.gz`
- `foreman-v1.2.0.apk`
- `SHA256SUMS`
- `SHA256SUMS.sig`
- `foreman-release-cert.pem`

The Linux archive and Android APK are accepted only when their checksums and
the signed release manifest validate against Foreman's pinned release
certificate.
